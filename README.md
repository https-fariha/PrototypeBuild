# Astral's Adventure - PrototypeBuild
The game builds that are ready for full play testing. 

How to play:
- Use the arrow keys to move the player around
- The main aim of the game is to collect resources from the terrain needed to fix the repair panel of the broken ship.
- To do so, collect the oxygen tanks in the ship to venture outside.
- Leave the ship and complete the obstacle courses to collect resource blocks (this will increase resource count) whilst also avoiding the aliens
- Colliding with the aliens decreases health by 20hp
- Return to the ship before the oxygen tanks/ health bar runs out
- Make contact with the repair panel when you have 3 resource blocks and pressing E to fix it to win the game
